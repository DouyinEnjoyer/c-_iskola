# Teremfoglaló, könnyű változat

A feladat leírása a tananyag oldalán található. A csomag tartalma:

- `TeremFoglalo/`: a te projekted. A `// TODO` megjegyzések mutatják, mit kell megírnod.
- `Ellenorzo/`: ellenőrző program. Nem kell módosítanod.
- `Forgatokonyvek/`: az ellenőrző bemenetei (`.be.txt`) és az elvárt kimenetek (`.ki.txt`).

## Futtatás

1. Nyisd meg a `TeremFoglalo.sln` fájlt Visual Studio 2022-ben (.NET 8).
2. Jobb klikk az `Ellenorzo` projekten, **Set as Startup Project**.
3. Indítás: **Ctrl+F5**. Az ellenőrző lefordítja a `TeremFoglalo` projektet, lefuttatja az összes forgatókönyvet, és kiírja, melyik egyezik az elvárt kimenettel.

A `ROSSZ` sor alatt látod, hányadik kimeneti sorban tér el a program a várt eredménytől.
